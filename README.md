# 零外部相依工控 Web SCADA 儀表板架構設計規格

### 本專案 `index.html` 是一套專為邊緣工控節點（如 ESP32）打造的**「零外部相依（Zero-Dependency）」單檔案 Web SCADA 儀表板**。
#### 系統將所有 HTML DOM 結構、CSS 視覺樣式、原生 Canvas 向量繪圖引擎以及雙向 WebSocket 通訊邏輯完整封裝於單一檔案內，無須連外網請求字型、Icon 圖示或第三方 JavaScript 函式庫（如 Chart.js、Bootstrap），具備極高的離線獨立運作能力與即時性。
---
一、 核心功能架構
```plaintext
┌─────────────────────────────────────────────────────────────┐
│ 1. 頂部自診斷 Ribbon (節點 IP、Uptime、RAM 殘量、氣壓、Wi-Fi 訊號) │
├─────────────────────────────────────────────────────────────┤
│ 2. 四軌向量扇形儀表卡片 (4-Column Sector Gauges)             │
│   [環境氣溫]       [相對濕度]       [物料芯溫]      [CO2/VOC/光照]  │
│   (VPD / 露點)   (加濕噴霧光暈)   (ΔT / 排風光暈)   (SGP40 / Lux)   │
├─────────────────────────────────────────────────────────────┤
│ 3. 雙軌工控執行機構控制台 (Actuator Control Console)         │
│   - 降溫排風扇 (Relay 18)：[自動 AUTO] / [手動 MANUAL (ON/OFF)]│
│   - 微霧加濕器 (Relay 19)：[自動 AUTO] / [手動 MANUAL (ON/OFF)]│
├─────────────────────────────────────────────────────────────┤
│ 4. 原生 Canvas 4 軸多維歷史折線圖 (10 分鐘 / 60 筆趨勢曲線)   │
└─────────────────────────────────────────────────────────────┘
```
---
二、 核心模組詳細解析
1. 頂部自診斷狀態列（System Diagnostic Ribbon）
設計定位：工控現場 $24/7$ 長時間不間斷運轉之主機健康監控。
監控參數明細：
連線節點（Node）：標明連線路徑來源，支援 AP 直連（`192.168.4.1`）、內網路由器動態 IP、mDNS（`esp32.local`）或離線本機預覽模式。
運作時間（Uptime）：微秒轉化為 `HH:MM:SS` 格式，精確監控微控制器連續開機時間。
可用記憶體（Heap RAM）：即時轉換為 $\text{KB}$，監控 ESP32 SRAM 堆疊動態，防範記憶體洩漏（Memory Leak）引發崩潰。
大氣壓力（BMP280）：即時大氣壓數值（$\text{hPa}$），作為環境微氣候與密閉室正負壓差的重要指標。
無線品質（RSSI）：以 $\text{dBm}$ 監控 Wi-Fi 訊號強度，確保工業現場連線品質。
---
2. 四軌向量扇形儀表卡片（含邊緣計算衍生指標）
每軌卡片皆包含動態向量指針、3 段式彩色警報弧線、即時數值面板、雙組衍生副標籤以及三色動態狀態 LED。
儀表項目	採樣感測器	量程範圍	邊緣計算衍生指標 / 視覺回饋
環境氣溫	SHT30	$15.0 \sim 35.0^\circ\text{C}$	整合硬體端即時計算之飽差（VPD）與露點溫度（Dew Point）。
相對濕度	SHT30	$60.0 \sim 90.0%\text{RH}$	連動微霧加濕狀態；加濕器啟動時卡片觸發霓虹冰藍呼吸光暈（`.hum-active`）。
物料芯溫	DS18B20 探棒	$15.0 \sim 35.0^\circ\text{C}$	- 綠區安全：$< 25.0^\circ\text{C}$<br>- 黃區警示：$25.0 \sim 30.0^\circ\text{C}$<br>- 紅區臨界：$> 30.0^\circ\text{C}$<br>- 整合生物代謝溫差：$\Delta T = T_{\text{core}} - T_{\text{air}}$<br>- 超溫或強制排風時外框切換為霓虹深紅警報光暈（`.fan-active`）。
空氣品質與照度	SCD40 + SGP40 + BH1750	$400 \sim 2000\text{ ppm}$	整合 Sensirion VOC 異味指數（$0 \sim 500$）與環境光度（$\text{Lux}$）。
---
3. 雙軌執行機構控制台（閉迴路自動 / 人工手動雙向控制）
控制台提供兩組符合工控邏輯的雙切保護迴路，兼顧自動化與現場檢修需求：
A. 降溫排風扇（Relay 18）
自動模式（AUTO）：
手動控制按鈕強制反灰鎖定，防止人為誤觸。
執行具備遲滯特性的閉迴路溫度控制：
$$\begin{cases}
T_{\text{air}} \ge 30.0^\circ\text{C} & \implies \text{排風扇啟動 (ON)} \
T_{\text{air}} \le 28.5^\circ\text{C} & \implies \text{排風扇停止 (OFF)}
\end{cases}$$
預留 $1.5^\circ\text{C}$ 死區（Deadband），防止繼電器頻繁切換造成跳火或硬體耗損。
手動模式（MANUAL）：
解除連鎖按鈕鎖定，賦予工程人員強制切換權限（`強制啟動 ON` / `強制停止 OFF`）。
B. 微霧加濕器（Relay 19）
自動模式（AUTO）：
手動控制按鈕鎖定，啟用濕度閉迴路遲滯反饋控制：
$$\begin{cases}
\text{RH} \le 70.0% & \implies \text{加濕器啟動 (ON)} \
\text{RH} \ge 80.0% & \implies \text{加濕器停止 (OFF)}
\end{cases}$$
建立 $10.0%\text{RH}$ 的回差防護區間，確保霧化系統運轉穩定。
手動模式（MANUAL）：
現場測試、管路排空或清洗維護時，可解除連鎖手動切換 `ON` / `OFF`。
---
4. 原生 Canvas 4 軸多維歷史趨勢圖
繪圖架構：不依賴任何第三方圖表框架，純粹調用 HTML5 原生 `<canvas>` API 進行向量繪製。
緩衝機制：採用 FIFO 佇列緩存固定 $60$ 筆資料點（以每 $10$ 秒一筆計算，精確對應 $10$ 分鐘的滑動時間窗口）。
多軸呈現：同屏疊加氣溫、濕度、芯溫與 $\text{CO}_2$ 趨勢曲線，並透過坐標縮放運算保證各維度數值可視性。
---
三、 技術特性與優勢
極致輕量化：單一 `.html` 文件體積小，可直接存放於 ESP32 的 SPIFFS / LittleFS 檔案系統或以 Gzip 壓縮寫入 PROGMEM。
零外網依賴：完全消除因現場外網中斷導致 CDN 載入失敗的風險，適應封閉式 OT 工業網路環境。
雙向通訊保障：藉由原生 WebSocket 協議保持雙向長連接，具備低延遲推播與即時指令反饋特性。
